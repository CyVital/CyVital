## Project Overview

**CyVital** is dedicated to providing modular hardware in the form of sensors and its corresponding software counterpart to read, analyze and display data seen within physiological sensors. This system was created to develop lab modules for BME3500 - Bioinstrumentation at Iowa State University. More information about this project can be found on our [website](https://sdmay26-06.sd.ece.iastate.edu/).
